# Andrew DePasquale's Computer Science ePortfolio

Welcome to my Computer Science ePortfolio. This portfolio represents my growth throughout the Computer Science program at Southern New Hampshire University and demonstrates my skills in software design and engineering, algorithms and data structures, databases, and secure software development.

## Professional Self-Assessment

Completing the Computer Science program at Southern New Hampshire University and developing this ePortfolio have helped me recognize how much my technical knowledge and problem-solving abilities have developed throughout the program. When I first began this path, much of my experience focused on learning individual programming concepts and understanding how to make programs function correctly. As I progressed through the coursework, I gained experience working with multiple programming languages, development environments, databases, software architecture and security practices. The capstone brought these areas together by requiring me to return to previous projects, evaluate them and make meaningful improvements. This process has helped me showcase my strengths in problem solving, software development and continuous learning while preparing me for my professional goal of transitioning into a software development career.

My coursework has also strengthened my ability to collaborate and communicate in a professional environment. Throughout the program, discussion assignments and project work required me to explain technical concepts, respond to the ideas of classmates and consider alternative approaches to solving problems. These experiences reinforced that software development is not only about writing code, but developers also need to communicate technical information clearly and understand the requirements of users and other stakeholders. My professional experience at the MBTA has reinforced these skills by requiring me to work with others, evaluate information and communicate findings accurately. Combining these experiences with my computer science education has helped me understand the importance of collaboration, documentation and clear communication when developing technical solutions.

My understanding of data structures and algorithms has developed significantly throughout my time here. Coursework required me to consider not only whether a solution produces the correct result, but also how information is organized and how algorithms make decisions. I worked with concepts including searching, sorting, data structures and algorithm efficiency, as well as more advanced applications such as reinforcement learning. These experiences strengthened my ability to examine a problem, determine how data should be represented and select an appropriate approach for processing that data. They also taught me the importance of evaluating results carefully rather than assuming that a working program is automatically an effective solution.

Software engineering has been another major area of growth. Throughout the program, I developed applications using languages and technologies including Java, C++, Python, JavaScript and web development frameworks. I gained experience working with different development environments and learned how application components interact rather than viewing individual pieces of code in isolation. Coursework involving mobile development, full stack development and software design demonstrated how user interfaces, application logic, APIs and persistent data must work together. I also learned the importance of maintainability, input validation, error handling and separation of responsibilities. The capstone strengthened these skills by requiring me to analyze existing applications and improve them without disrupting their existing functionality.

My database coursework expanded this understanding by demonstrating the role persistent data plays in larger software systems. I gained experience with both relational and NoSQL database concepts and worked with technologies such as SQLite and MongoDB. Working with databases taught me to consider schema design, queries, validation, indexing and the connection between stored information and application logic. Rather than treating the database as a separate component, I learned to consider how database design decisions affect the reliability, security and performance of the entire application.

Security has also become an important part of how I approach software development. My secure coding coursework gave me experience examining vulnerabilities such as numeric overflow and underflow, SQL injection, buffer related problems and improper exception handling. I practiced techniques including input validation, exception handling, secure database interaction and defensive programming. These experiences changed the way I evaluate software because I now consider how unexpected or malicious input could affect an application in addition to considering its expected behavior. The capstone reinforced this security mindset by requiring security considerations to be incorporated into enhancements rather than treated as a separate feature added at the end of development.

Developing the ePortfolio also helped shape my professional goals and values. My goal is to transition into a software development role where I can continue developing my programming and problem-solving abilities while contributing to useful software solutions. The variety of technologies I encountered throughout the program demonstrated the importance of being adaptable and willing to learn unfamiliar tools. I value software that is reliable, maintainable, secure and useful to its intended users. I also recognize that graduating with a computer science degree is not the end of the learning process. Technologies and development practices continue to evolve, making continued learning an important part of the career I am pursuing.

The artifacts presented in this ePortfolio demonstrate these abilities across three areas of computer science. The Software Design and Engineering artifact is an Android inventory management application originally developed in CS 360 and enhanced to improve its functionality, organization, validation and inventory management capabilities. The Algorithms and Data Structures artifact is a reinforcement learning Treasure Hunt project from CS 370 that was enhanced with additional training controls, performance metrics and evaluation capabilities. The Databases artifact is the Travlr Getaways full stack application from CS 465, which was enhanced through stronger database validation, controlled querying, indexing and error handling. Together, these artifacts demonstrate my ability to revisit existing software, identify opportunities for improvement and apply computer science principles to create more capable and reliable solutions.

Although each artifact emphasizes a different area, together they demonstrate how the skills developed throughout the Computer Science program are connected. Effective software requires more than knowledge of a single programming language or technology. Software engineering practices provide the structure for building and maintaining applications, algorithms determine how problems and data are processed, databases provide reliable access to persistent information and security considerations help protect the application and its users. The enhancements presented in this portfolio demonstrate my growth in these areas and represent the foundation I will continue to build upon as I pursue a career in software development.
